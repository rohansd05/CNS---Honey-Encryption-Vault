# ADR-002: Run honeycore on the server (Python), not in the browser

- Status: Accepted
- Date: 2026-10-03
- Source: PROJECT-BRIEF.md §13

## Context
Ideally the master password never leaves the client. A client-side implementation would need the PCFG model, Argon2id and AES-CTR in WASM/JS, which is out of reach for a 4-week course project with five parallel tracks.

## Decision
honeycore is a pure Python library called by the FastAPI backend. The master password is sent over HTTPS per request, used, and never stored or logged. Client-side WASM is future work.

## Consequences
- One implementation, easy to test with pytest/hypothesis and to evaluate.
- A compromised server sees master passwords as users unlock (full server compromise is out of scope).
- Stolen-DB attacks (A1) are still fully addressed: the DB holds no oracle.
- Unlock latency depends on the server's CPU (Argon2 profiles tuned for Render).
