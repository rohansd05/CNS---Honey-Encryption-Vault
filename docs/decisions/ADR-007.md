# ADR-007: Password model v2 and PIT seed test

- Status: Accepted
- Date: 2026-10-17
- Source: PR #66, PR #71, docs/eval-report.md §4.2, §6

## Context
`pcfg-password-v1` was trained on Zipf-ranked weights, but the held-out passwords carry real counts, and the held-out file was the first 50,000 held-out values (the most frequent ones). The seed χ² tests (bytes, top 4 bits of used ints) only see model misfit when a distribution's total T is near 2³¹; for small T the codec's uniform multiple of T fills the high bits and hides it.

## Decision
- Passwords use `pcfg-password-v2`, trained on `rockyou-withcount` with real counts (#66).
- Held-out files are a seeded uniform random sample of the held-out split (reservoir, seed 7).
- The evaluation adds a PIT seed test, `u = (r mod T + U) / T`, which is uniform under a perfect fit for any T (#71).
- No username v2 is built (eval-report §6); usernames stay on `pcfg-username-v1`.

## Consequences
- Training and held-out weights now match; the byte/int seed tests pass for v2 but are not evidence of fit — the PIT test is.
- Username seed tests and the as-stored username distinguisher still fail; this is a documented limitation.
- Any future model is judged by the PIT test and the distinguisher, not by the byte/int tests alone.
