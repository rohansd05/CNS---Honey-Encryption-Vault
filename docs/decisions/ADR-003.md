# ADR-003: Separate login password and master password

- Status: Accepted
- Date: 2026-10-03
- Source: PROJECT-BRIEF.md §13

## Context
Honeywords store k sweetword hashes of the login password with a cheap-ish server KDF. If the login password equalled the master password, cracking those hashes would give the attacker at most k master-password candidates, collapsing the honey-encryption guarantee.

## Decision
Users have two passwords. Registration rejects `login_password == master_password` (compared with `hmac.compare_digest`). Nothing derived from the master password is stored.

## Consequences
- Honeywords and HE protect independent secrets.
- Slightly worse UX (two passwords); the UI explains why.
- Users could still choose related passwords; we only enforce inequality.
